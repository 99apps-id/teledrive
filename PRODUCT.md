# Product

## Register

product

## Users

TeleDrive is for self-hosted users who want a familiar file manager for private Telegram-backed storage. They are usually managing files, checking storage readiness, and preparing uploads from a desktop browser.

## Product Purpose

TeleDrive provides an API-first web file manager where Telegram is only a storage transport owned by the authenticated user. Success means users can manage files with the confidence and predictability of a desktop file explorer while TeleDrive handles metadata, upload jobs, and Telegram private-channel storage behind the scenes.

## Brand Personality

Familiar, disciplined, practical. The product should feel trustworthy and operational rather than promotional.

## Anti-references

Do not look like a Telegram client, chat app, marketing landing page, or decorative SaaS dashboard. Avoid oversized hero typography, floating card layouts, glassy effects, and social/messaging affordances.

## Design Principles

- Prefer familiar file-management patterns over novelty.
- Keep Telegram implementation details visible only where they help users understand storage status.
- Design for repeated desktop workflows first, with responsive fallbacks for smaller screens.
- Make API-first architecture feel calm and inspectable, not technical for its own sake.
- Use restrained product UI states: selected, hover, disabled, loading, warning, and ready.

## Accessibility & Inclusion

Target WCAG AA contrast. Preserve keyboard focus, clear hit areas, reduced motion compatibility, and labels that describe user actions in plain language.
